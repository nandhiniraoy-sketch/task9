# Task 9 - NumPy Arrays and Basic Operations

## Objective

Learn NumPy basics by creating arrays, exploring their attributes, and
performing arithmetic operations.

## Tools Used

-   Python
-   NumPy
-   Jupyter Notebook / VS Code

## Programs

### 1. One-Dimensional Array

``` python
import numpy as np
arr = np.array([10,20,30,40])
print(arr)
```

### 2. Two-Dimensional Array

``` python
import numpy as np
arr = np.array([[1,2,3],[4,5,6]])
print(arr)
```

### 3. Array Attributes

``` python
import numpy as np
arr = np.array([[1,2,3],[4,5,6]])
print("Shape:", arr.shape)
print("Dimensions:", arr.ndim)
print("Size:", arr.size)
print("Data Type:", arr.dtype)
```

### 4. Arithmetic Operations

``` python
import numpy as np
a=np.array([1,2,3])
b=np.array([4,5,6])
print("Addition:",a+b)
print("Subtraction:",a-b)
print("Multiplication:",a*b)
print("Division:",a/b)
```

## Output

-   Created 1-D and 2-D arrays.
-   Displayed shape, ndim, size and dtype.
-   Performed arithmetic operations.

## Learning Outcome

-   Understood NumPy arrays.
-   Learned array attributes.
-   Performed numerical operations.

## Conclusion

This task introduced the basics of NumPy, which is widely used in Data
Science and Machine Learning.
